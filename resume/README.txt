RESUME FOLDER
=============

Save your resume PDF in this folder as:

  Alexis-Gonzalez-Resume.pdf

The Resume icon on the AlexisOS desktop opens resume.html in a new
browser tab, and that page embeds this PDF. Once you drop the file
in with the exact name above, the resume page will display it.

TIPS
----
- Keep the filename exact (case matters when hosted on Render/Linux).
- Most browsers include a built-in download button in their PDF
  viewer, so visitors can download from the page itself.
- To use a different filename, update the `data="..."` attribute
  inside resume.html.

Until the PDF is added, the resume page shows a friendly note
telling visitors it isn't uploaded yet, so nothing looks broken.
